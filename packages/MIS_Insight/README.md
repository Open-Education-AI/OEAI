# MIS Insight package

| | |
|---|---|
| Type | Package |
| Depends on | One foundational MIS module (Wonde, Arbor or Bromcom); shared foundations `oeai_py`, `oeai_logger` |
| Status | Early build. Successor work is the `mis_trends` package in the private repository (1.0.0, July 2026) |

Trust-wide MIS insight: standard analysis across schools of attendance, exclusions and conduct, delivered as a Power BI report over the Gold layer.

* `oeai_pkg_gat_edst.ipynb`: prepares the Gold tables the report consumes.
* The report definition is in [`report/`](../../report/) at the repository root (`oeai_report_mvp`).

See [asset versions](../../README.md#assets-and-versions) and the [roadmap](../../ROADMAP.md).

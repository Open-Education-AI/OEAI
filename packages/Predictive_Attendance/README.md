# Predictive Attendance package

| | |
|---|---|
| Type | Package (predictive; Tier 2 review) |
| Depends on | One foundational MIS module (Wonde, Arbor or Bromcom); shared foundations `oeai_py`, `oeai_logger` |
| Status | Early build. The current `predictive_attendance` package is in the private repository under Tier 2 review |

Understands historical attendance patterns and predicts future attendance and attendance risk for intervention. Led with Dixons Academies Trust as the development partner.

* `oeai_pkg_dat_ml_attendance.ipynb`: feature preparation, model training and scoring.

Predictive outputs support professional judgement; they are not determinations about a pupil. Read the data-ethics notes in the private repository before operational use.

See [asset versions](../../README.md#assets-and-versions) and the [roadmap](../../ROADMAP.md).
